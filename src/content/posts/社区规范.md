# 第一部分　评论公约

## 一、评论规范

在本站评论时，请确保您的评论符合以下规则：

**1.1 内容相关**

评论内容应与文章**内容相关或具有讨论价值**。禁止无意义刷屏、灌水等行为，也不欢迎与本站无关的争议、挂人、跨站纠纷、引战内容。

**1.2 禁止商业推广**

昵称、邮箱、网址、评论内容等**不得包含任何商业推广信息**。

**1.3 合法合规**

昵称、邮箱、网址、评论内容等须**符合中华人民共和国相关法律法规**，不得包含欺诈链接、色情或其他违法信息。

**1.4 尊重他人**

昵称、邮箱、网址、评论内容等**不得包含侮辱、歧视、仇恨、骚扰等针对他人的内容**。

## 二、违规处理

**2.1 处理措施**

违反上述规范的，本站有权根据规则**删除、折叠或屏蔽**您的评论，并视情节严重程度采取限制评论、列入黑名单等措施。

**2.2 申诉渠道**

本站对评论的处理以**必要、适度**为原则。您对处理结果有异议的，可通过 `xiaoyuer2333@outlook.com` 提出申诉

## 三、评论系统说明

本站评论系统使用 Giscus，评论数据存储于 GitHub Discussions。发表评论需通过 GitHub OAuth 授权 Giscus 应用代表您发布内容。

> [!WARNING] WARNING
> 发表评论后，您可能会通过 GitHub 收到该 Discussion 的后续通知。您可以前往[源代码仓库](https://github.com/1312333/Firefly)的 Discussions 页面，取消订阅相关讨论。Giscus 本身不存储您的评论数据，数据由 GitHub 依据其隐私政策处理。

**您对您的评论内容拥有完全的著作权。同时，您也需要对您所发布的评论承担全部责任。**

如果您认为本站的评论管理方式不符合期待，可以选择不在本站发表评论。
